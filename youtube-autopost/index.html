2. Aperçu des 30 prochains jours

    3. Mise en service

    1. Créer un projet sur Google Cloud, y activer YouTube Data API v3.
    2. Écran de consentement OAuth → Publier l'application (sinon le jeton meurt au bout de 7 jours).
    3. Identifiants → Application Web → URI de redirection : https://developers.google.com/oauthplayground.
    4. Sur OAuth Playground : ⚙ → Access type: Offline + vos identifiants → scope youtube.upload → copier le Refresh token.
    5. GitHub → Settings → Secrets → Actions : YT_CLIENT_ID, YT_CLIENT_SECRET, YT_REFRESH_TOKEN.
    6. Déposer les vidéos dans youtube-autopost/videos/, fusionner dans main.
    7. Onglet Actions → « Short quotidien » → Run workflow pour un premier essai.
