Détail

Les nuits de week-end comptent les nuits de vendredi et de samedi : ce sont elles qui déséquilibrent le plus un planning, même quand le total de nuits est parfaitement partagé.

Les deux maisons

Les noms s'affichent partout dans le calendrier. Les couleurs restent lisibles en noir et blanc : la seconde maison est hachurée.

Rythme de base

Le rythme se répète en boucle. Les vacances et les échanges ponctuels viennent ensuite par-dessus.

Vacances et périodes particulières

Ajoutez chaque période réelle (vacances scolaires, ponts, séjour à l'étranger). Elle remplace le rythme de base sur ses dates.

Tout reste sur cet appareil. Rien n'est envoyé nulle part : il n'y a pas de serveur derrière cette page.

Le lien du planning contient toute la configuration encodée dans l'adresse elle-même. L'autre parent l'ouvre et voit exactement le même calendrier, sans compte ni application. Un lien reçu est une copie : les modifications de chacun restent chez lui.

Comment lire les rythmes

Les nombres indiquent des nuits consécutives, en alternance entre les deux maisons.

  • 7 / 7 — une semaine chacun, un seul échange par semaine.
  • 2-2-3 — l'enfant ne reste jamais plus de trois nuits loin d'un parent ; le week-end alterne. Souvent conseillé pour les jeunes enfants.
  • 2-2-5-5 — mêmes jours de semaine fixes toutes les semaines (utile pour les activités), week-ends alternés.
  • Week-ends alternés — résidence principale chez une maison, l'autre prend un week-end sur deux (12 nuits / 2 nuits).

Deux Maisons fonctionne entièrement dans votre navigateur. Aucun compte, aucun serveur, aucune donnée transmise : enregistrez la page (Ctrl+S) et elle marche hors connexion.
